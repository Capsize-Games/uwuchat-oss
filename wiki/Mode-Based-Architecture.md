# Mode-Based Architecture (Archived)

The mode-based architecture was a **planned** enhancement for intelligent query routing to specialized agents. This feature was designed but has not been implemented in the current codebase.

**Status:** ⛔ Not Implemented

The current agent architecture uses a single LangGraph workflow for all queries. Tools are available to the LLM based on the selected chat mode (Chat, Auto, RAG).
